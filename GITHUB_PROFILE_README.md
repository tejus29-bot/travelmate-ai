## 🌟 Featured Project

### ✈️ [TravelMate AI — AI Travel Planner](https://github.com/tejus29-bot/travelmate-ai)
> Full-stack AI SaaS platform that generates personalized day-by-day travel itineraries with smart budget breakdowns, interactive maps, and PDF exports.

- **Frontend:** React 18, Vite, Tailwind CSS, Framer Motion
- **Backend:** Python, FastAPI, Uvicorn, REST API
- **Database & Auth:** Supabase Cloud (PostgreSQL with Row Level Security)
- **Deployment:** Render Cloud
